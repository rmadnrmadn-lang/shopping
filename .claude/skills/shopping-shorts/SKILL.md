# 쇼핑쇼츠 (Shopping Shorts)

숏폼 커머스 영상을 **벤치마킹 → 패턴 추출 → 빈틈 발견 → 신규 기획**의 순서로 만든다.

이 순서가 중요한 이유: 잘 팔리는 숏폼은 창의성이 아니라 **검증된 비트 구조 위에 새로운 표면을 얹은 것**이다.
구조를 먼저 훔치고 표면을 새로 만들어야 "본 적 있는데 처음 보는" 영상이 나온다.
반대로 하면 (표면부터 만들면) 예쁘지만 안 팔리는 영상이 된다.

---

## 0. 먼저 확인할 것 — 소스에 실제로 접근 가능한가

레퍼런스 영상을 **실제로 보지 않고 벤치마킹했다고 말하면 안 된다.** 이건 이 스킬에서 가장 중요한 규칙이다.
URL 슬러그와 해시태그만 보고 내용을 추측하면 그럴듯한 거짓말이 만들어지고, 사용자는 그걸 근거로 돈을 쓴다.

작업 전에 확인한다:

- 영상 파일 / 스크린샷 / 화면 녹화가 있는가 → **최선.** 프레임 단위 분석 가능
- 캡션·해시태그·댓글 텍스트만 있는가 → 부분 분석 가능. 화면 연출은 모른다고 명시
- URL만 있고 네트워크가 막혀 있는가 → **벤치마킹 불가.** 추측하지 말고 사용자에게 소스를 요청

세 번째 경우, 이렇게 말한다: "링크에 접근이 안 됩니다. 영상 파일이나 스크린샷을 주시면 실제 분석하고,
지금 바로 진행하길 원하시면 니치 기반 추론으로 만들되 '실제 영상 분석 아님'을 명시하겠습니다."

접근 가능한 것과 추측한 것은 최종 산출물에서도 계속 구분해서 표기한다.

## 1. 벤치마킹 — 영상 한 편씩 해부

레퍼런스마다 아래를 기록한다. 인상 비평("감각적이다")이 아니라 **재현 가능한 사실**을 적는 게 목적이다.
"좋았다"는 다음 영상 제작에 아무 도움이 안 되지만 "0.8초에 제품이 화면을 꽉 채운다"는 그대로 따라 할 수 있다.

| 항목 | 기록할 것 |
|---|---|
| 훅 (0~2초) | 첫 프레임에 **무엇이 보이는지**, 첫 자막 문장 그대로, 제품 등장 시점(초) |
| 비트 구조 | 컷별 역할과 길이. 예: `0-2 훅 / 2-6 작동 시연 / 6-9 전후 비교 / 9-12 CTA` |
| 컷 리듬 | 총 컷 수, 평균 컷 길이, 가장 긴 컷(어디서 숨을 쉬는가) |
| 카메라 | 고정/핸드헬드/짐벌, 앵글(로우·아이·탑), 클로즈업 비중 |
| 오디오 | 보이스오버 / BGM만 / 현장음(ASMR). 무음으로 봐도 이해되는가 |
| 자막 | 위치, 글자 수, 한 화면에 몇 줄, 색·외곽선 |
| 증명 | 무엇으로 신뢰를 만드는가 — 설치 현장, 실측, 내구 테스트, 가격표, 사용자 반응 |
| CTA | 있는가/없는가, 형태(프로필 링크·댓글 키워드·DM·사이즈 문의) |
| 수요 신호 | 상위 댓글 질문. **여기에 다음 영상 주제가 들어 있다** |

댓글을 볼 수 있다면 반드시 본다. "이거 얼마예요" "우리집 창문에도 되나요" 같은 반복 질문은
시장이 아직 답을 못 받은 지점이고, 그 질문 하나가 곧 다음 영상의 훅이 된다.

### 훅 유형 분류

기록한 훅을 아래로 분류해두면 다음 단계에서 빈틈이 보인다.

- **결과 선공개** — 완성된 상태를 먼저 보여주고 되감기
- **문제 제시** — 불편한 상황을 3초 안에 재연
- **감각/ASMR** — 소리·질감·움직임 자체가 훅 (무음 시청자에겐 안 통함, 주의)
- **비교** — 좌우 분할, 전후, A vs B
- **가격 충격** — 숫자를 먼저 던짐
- **역발상/금기** — "이거 사지 마세요", "업자들이 안 알려주는"
- **과정 몰입** — 시공·조립 과정을 빠르게

## 2. 교차 분석 — 공통점과 빈틈

개별 해부가 끝나면 레퍼런스 전체를 가로로 본다.

1. **공통 패턴** — 몇 편 이상에서 반복되는 구조. 이건 시장이 검증한 문법이니 **지킨다**
2. **분기점** — 영상마다 다르게 간 지점. 여기가 선택지다
3. **빈틈** — 레퍼런스 **아무도 안 한 것**. 여기가 "새로운 형태"의 출처다

빈틈을 찾을 때 유용한 질문:
- 전부 제품만 비추는가? → 사람·공간·생활 맥락이 비어 있다
- 전부 시공 과정인가? → 결과 이후의 삶(아침 햇살, 낮잠)이 비어 있다
- 전부 조용한 ASMR인가? → 말로 설득하는 포맷이 비어 있다
- 전부 예쁜 집인가? → 좁은 집, 오래된 창틀, 실패 사례가 비어 있다
- 전부 판매자 시점인가? → 구매자 시점(고르는 기준, 후회 포인트)이 비어 있다

**새로움은 장르 이탈이 아니라 빈칸 채우기다.** 검증된 비트 구조는 유지하고 빈칸 하나만 바꾼다.
구조까지 새로 만들면 그냥 안 팔리는 영상이 된다.

---

## 3. 신규 기획 산출물

아래 형식으로 낸다. 기획안 1개가 아니라 **서로 다른 빈틈을 노리는 3안**을 내는 게 기본이다.
숏폼은 타율 게임이라 한 발만 쏘면 배울 게 없다.

```
## 컨셉 N: [한 줄 이름]
- 노리는 빈틈: [2번에서 찾은 것]
- 차용한 구조: [어느 레퍼런스의 무슨 비트]
- 타깃 시청자: [구체적 상황 — "이사 앞두고 커튼 알아보는 신혼부부"]
- 목표 지표: 3초 유지율 / 완주율 / 프로필 유입 중 무엇

### 비트 시트
| 시간 | 화면 | 자막 | 오디오 |
|---|---|---|---|
| 0.0-1.5 | ... | ... | ... |

### 촬영 지시
- 컷 목록 (앵글, 거리, 움직임)
- 필요한 소품·장소·인물
- 반드시 담아야 하는 순간 1개

### 자막 전문
(무음으로 봐도 메시지가 완결되는지 확인)

### CTA
[문구 + 착지점]
```

### 기획할 때 지키는 것

**0.5초 안에 시선을 잡는다.** 숏폼 이탈은 대부분 1초 안에 일어난다.
로고, 인트로, "안녕하세요"는 전부 삭제한다. 첫 프레임이 곧 썸네일이다.

**무음 시청을 기본으로 본다.** 상당수가 소리 없이 본다.
자막만 읽어도 제품과 이유가 전달되는지 확인한다. 소리는 보너스로 취급한다.

**루프를 노린다.** 마지막 프레임이 첫 프레임과 이어지면 재생수가 자연히 늘어난다.
시청 완료 후 자동 재생되면서 이탈 없이 다시 도는 구조가 알고리즘에 유리하다.

**한 영상에 메시지 하나.** 방수·차광·가격·시공을 다 넣으면 아무것도 안 남는다.
나머지는 다음 영상의 소재로 남겨둔다 — 시리즈가 계정을 키운다.

**댓글을 설계한다.** 일부러 질문을 유발하는 요소(사이즈 미표기, 가격 미공개, 의외의 선택)를
하나 심어두면 댓글이 붙고, 댓글은 도달로 이어진다.

---

## 4. 언어·시장

레퍼런스가 여러 시장이면 시장별로 문법이 다르다는 걸 반영한다.
자막 밀도, 가격 노출 관습, CTA 방식이 시장마다 다르므로 **번역이 아니라 현지 재작성**으로 다룬다.
사용자가 목표 시장을 안 밝혔으면 물어본다.
