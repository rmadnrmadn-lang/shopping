# 아이템 리뷰 포맷

단일 제품을 리뷰하는 숏폼. 벤치마킹 없이도 쓸 수 있는 검증된 골격이라
제품 정보만 채우면 바로 촬영 대본이 된다.

리뷰 숏폼이 일반 홍보 숏폼과 다른 지점: **시청자는 이미 사려고 마음이 기운 상태로 들어온다.**
그래서 "이게 뭔지"를 설명할 필요는 거의 없고, "사도 되는지"에 답해야 한다.
설명형으로 쓰면 지루해지고, 판단형으로 써야 끝까지 본다.

## 시작 전에 필요한 것

아래가 없으면 대본을 쓰지 말고 사용자에게 요청한다. **추측해서 채우면 허위 리뷰가 된다.**

| 항목 | 왜 필요한가 |
|---|---|
| 제품명·카테고리 | 전부의 출발점 |
| 가격 | 판단 기준. "이 값이면"이 리뷰의 축이다 |
| 핵심 스펙 2~3개 | 검증할 대상 |
| 실사용 여부·기간 | 안 써봤으면 리뷰가 아니라 소개다. 정직하게 구분 |
| 실제 단점 1개 | **없으면 리뷰가 광고로 읽힌다** |
| 경쟁 제품/대안 | 비교 축 |

실사용 경험이 없다면 리뷰 형식을 쓰지 않는다. "써봤다"는 거짓 진술은
플랫폼 정책 위반이면서 계정 신뢰를 태우는 행위다. 그 경우 "언박싱"이나 "스펙 비교"로 포맷을 바꾼다.

## 비트 골격 (15~20초)

| 구간 | 역할 | 분량 |
|---|---|---|
| 훅 | **판정을 먼저 던진다** — "이 가격이면 삽니다" / "이건 반품했습니다" | 0~2초 |
| 정체 | 뭔지 1초 안에. 제품 풀샷 | 2~4초 |
| 검증 1 | 가장 큰 장점을 **행동으로** 증명 (말로 X) | 4~8초 |
| 검증 2 | 실제 단점. 여기서 신뢰가 생긴다 | 8~12초 |
| 판정 | 누구에게 맞고 누구에겐 아닌지 | 12~16초 |
| CTA + 루프 | 훅 구도로 복귀 | 16~18초 |

### 왜 판정을 먼저 던지는가

리뷰 영상의 결론을 끝에 두면 시청자는 결론을 기다리다 이탈한다.
결론을 0초에 주면 "왜?"가 생겨서 남는다. 결론은 훅이고, 근거가 본론이다.

### 왜 단점을 반드시 넣는가

장점만 나열한 리뷰는 광고로 분류되고, 시청자는 광고를 끝까지 보지 않는다.
단점 하나가 나머지 장점 전부의 신뢰를 담보한다. 단, **치명적이지 않은 진짜 단점**이어야 한다.
지어낸 단점("너무 예뻐서 문제")은 즉시 들통난다.

## 촬영 기본

- 제품이 손에 들려 움직이는 컷이 정지 컷보다 강하다 — 크기·질감이 전달된다
- 스펙 숫자는 말하지 말고 **자막으로**. 무음 시청자가 절반이다
- 가격은 화면에 띄운다. 리뷰에서 가격을 숨기면 신뢰가 깎인다
- 개봉 순간, 작동 순간 같은 **되돌릴 수 없는 컷**은 반드시 첫 시도에 촬영

## 표기 의무

대가성(협찬·수수료·제휴 링크)이 있으면 영상 안에 명시한다.
쿠팡 파트너스 등 제휴 링크는 국내 기준 대가 표시 대상이다.
자막으로 "유료 광고 포함" 또는 "파트너스 활동으로 수수료를 받습니다"를 넣는다.
숨기면 계정 리스크이자 법적 리스크다.
